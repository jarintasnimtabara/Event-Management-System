Card ID: US-07

Card Title:
Create & Edit Event Form — Mohona

Assigned To:
Mohona

User Story:
As an Organizer, I want to create and publish an event with valid details (title, category, venue) so that guests can see and register for it.

Description:
This is the form organizers use to add a new event. It has fields for the event title, category, date, time, venue, capacity, and a short description, plus a banner image upload. Once everything is filled in, clicking Publish Event makes it live for guests.
